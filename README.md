# Bridget Delicious Chapats - Official Website

Welcome to the official repository for the **Bridget Delicious Chapats** website. This project was developed as a final semester practical exam for the Website Design and Internet Technology course. 

## 🔗 Live Website
You can view the live, published website here: 
**[https://nabbonabridge50.github.io/bridget-chapats/](https://nabbonabridge50.github.io/bridget-chapats/)**

## 📖 Project Overview
Bridget Delicious Chapats is a local food business based in Kampala, Uganda. This website serves as a digital storefront to showcase the menu, display food photography, provide catering information, and allow customers to place orders directly via an integrated form.

## 🛠️ Technologies Used
*   **HTML5:** Semantic structure and accessible forms.
*   **CSS3:** Styling, Flexbox layouts, CSS Grid, Media Queries, and `@keyframes` animations.
*   **Web3Forms API:** Handling secure form submissions.
*   **GitHub Pages:** Live hosting and deployment.
